# API-Linkging-Bridge

一款轻量 API 转发代理桥，监听本地自定义端口，自动完成请求转义、协议适配，将流量转发至上游 API 服务商，并把响应分流回传给本地调用端。

✅ 解决模型列表扫描时 404 报错

✅ 规避长对话 / 大请求链路超时

✅ 双版本：图形化桌面 GUI + 纯终端 CLI

✅ 轻量无复杂依赖，开箱即用

# 使用方法

**图形化版**

1：双击运行该软件

2：到 **链路管理** 页设置链路名称、Base URL、模型名、API Key、端口、转换模式等（根据自身情况设置）

3：点击 **测试连接** 按钮

4：回到 **运行控制台** 页，选择链路并启动

**终端 CLI 版**

1：双击运行该软件，或在终端内启动。

2：输入 **add** 命令，添加链路，根据提示依次设定

3：配置完后，通过键盘的 **↑↓** 键移动高亮条选择链路（高亮的链路即为选中）

4：选择完毕后，输入 **start** 启动链路，输入**stop**停止链路

5：输入 **delete** 删除所选链路，**请确保选择正确后再执行，避免误删**

6：通过 **stats** 可查看链路信息， **help** 可查看所有命令及其用法

# 注意：启动链路前请先检查设置的端口是否被其他软件占用，否则将不能正常运行！！！
